# Broken Link Checker and Dead Link Detector

[![Broken Link Checker](https://img.shields.io/badge/TAVARDT-Broken%20Links-5b3cf5.svg)](https://tools.tavardt.com/ca/broken-link-checker/)
[![Python](https://img.shields.io/badge/Python-3.8%2B-blue.svg)](https://www.python.org/)

Comprehensive auditing of bilingual internal paths and outbound link health.

Engineered and maintained by the web architecture practice at **TAVARDT**.

***

## Broken Link Detection Features

* **Bilingual Link Verification**: Automated validation of English and French navigational paths and outbound citations.
* **HTTP Error Code Identification**: Pinpoint 404 Not Found and internal server errors in real time.
* **Search Engine Crawl Efficiency**: Protect crawl budget from broken links and broken canonical destinations.
* **Anchor Text Usability**: Ensure clear, accessible text anchors across all page components.
* **Link Health Index**: Technical assessment from 0 to 100 with categorized defect logging.

***

## Installation and Execution

Compatible with Python 3.8+ using standard modules.

```bash
git clone https://github.com/TAVARDT-Canada/broken-links-checker-ca.git
cd broken-links-checker-ca
python broken_links_scanner.py https://enterprise.ca
```

JSON output mode:

```bash
python broken_links_scanner.py https://enterprise.ca -json
```
